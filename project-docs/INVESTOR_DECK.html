Masalah

Perusahaan multi-client mengulang masalah storage yang sama untuk setiap pelanggan.

  • Credential provider tersebar di banyak aplikasi dan environment.
  • Client harus memahami endpoint, region, bucket, serta policy provider.
  • Quota, audit, dan folder access tidak konsisten.
  • Migrasi provider menyentuh aplikasi bisnis satu per satu.
N × M
N aplikasi × M provider menciptakan integration sprawl.

Biaya tersembunyi bukan hanya storage—tetapi engineering, support, credential risk, dan perubahan provider.

Arsitektur yang menjaga margin

Control plane shared; data plane dipilih sesuai kebutuhan dan willingness to pay.

Managed direct

Client mengirim file langsung ke provider melalui presigned URL.

  • COGS dan bottleneck gateway lebih rendah.
  • Provider hostname dapat terlihat.
  • OPNsense tidak melihat trafik tersebut.

Full proxy

Semua byte melewati gateway produk.

  • Stable endpoint dan provider tersembunyi.
  • Bandwidth dapat di-shape.
  • COGS, TLS, socket, dan HA meningkat.
Default: hybrid

Direct untuk volume besar; proxy sebagai fitur premium atau requirement khusus.

OPNsense: hard cap, bukan billing engine

Per-tenant entitlement tetap ditegakkan oleh aplikasi dan Redis.

Product wedge

Mulai dari governance yang dibayar pelanggan—bukan mengejar seluruh fitur S3.

MVP yang dijual

  • Multi-tenant organization dan RBAC.
  • Provider registry dan bucket import.
  • Virtual namespace dan file explorer.
  • Scoped API credentials dan quota.
  • Priority/weighted placement.
  • Audit, usage, dan reconciliation.

Sengaja ditunda

  • Full AWS S3 parity.
  • Replication dan erasure coding.
  • Non-S3 protocols.
  • Lifecycle/versioning normalization.
  • Private-network connector.
  • Dedicated full stack per tenant.
Custom REST API lebih dulu; S3 facade setelah demand terbukti 06

Unit economics

Gross margin hanya menarik bila sebagian besar byte tidak melewati gateway.

Direct-heavy mix

75–82%
Target gross margin setelah scale awal.

Customer membayar storage provider; platform menanggung control plane dan limited transfer.

Proxy-heavy mix

<50%
Bisa terjadi bila bandwidth dijual terlalu murah.

Harus ada per-GB charge, hard cap, atau dedicated gateway fee.

Provider economics tidak seragam

R2 menyatakan direct egress gratis; B2 memberi free egress sampai batas tertentu; AWS bergantung region/path.

OPNsense menjaga fairness, bukan margin

Shaping membatasi Mbps tetapi tidak menghapus biaya per GB atau transit.
